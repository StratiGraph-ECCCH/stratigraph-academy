StratiGraph Academy
===================

Where you learn to work with the StratiGraph tools: the whole pipeline, from the edge of a
trench to a published study, the partners' tools included.

Two layers. **Competence nodes** are the atoms — one thing explained once, or a pointer to
wherever it is already explained well. **The five working phases (0–4)** are the
processes: the real sequence of an investigation, and, in the path, the modules to pass.

One source, two outputs. The content is markdown in this repository, English as the
source. From it comes a site to read, and — when completions have to be counted — a
Moodle course space, provisioned with the same pipeline EM Academy already uses
(markdown → HTML fragments → GIFT quizzes).

Until 19 November 2026 this repository was ``stratigraph-server-doc``, and briefly
``stratigraph-manual``: its node and field chapters now live beside the code they
describe, in ``stratigraph-server`` and ``stratigraph-stratifield``. What stayed here is
the high level, which is what the Academy is for.

The Extended Matrix **method** is taught by EM Academy; the tools' manuals live beside
their code. This repository cites both and copies neither.
